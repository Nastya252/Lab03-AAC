## Самостоятельное исследование 
# Исследование 1. Что находится внутри int
Число: 1
В hex: 0x00000001
Little-endian: True
Байты числа:
01-00-00-00

Число: 256
В hex: 0x00000100
Little-endian: True
Байты числа:
00-01-00-00

Число: 65536
В hex: 0x00010000
Little-endian: True
Байты числа:
00-00-01-00

1. Почему число 1 занимает 4 байта, хотя для его записи достаточно одного байта?
Тип int в C# жёстко определён как 4-байтовый (32 бита). Память под переменную выделяется под размер типа. Если бы размер зависел от значения, компьютеру пришлось бы каждый раз вычислять, сколько байт занимает число, - это усложнило бы работу процессора.
2. Что изменяется в байтовом представлении числа 256?
Единица сдвигается из первого байта во второй: 01-00-00-00 -> 00-01-00-00. 256 не помещается в один байт (максимум 255), поэтому «переходит» в следующий разряд.
3. Почему число 65536 уже требует другого набора байтов?
65536 = 2^16, то есть для её записи нужны 17 бит - больше двух байтов. Единица оказывается в третьем байте: 00-00-01-00.

# Исследование 2. Почему порядок байтов имеет значение
Число: 305419896
В hex: 0x12345678
Little-endian: True
Байты числа:
78-56-34-12
На архитектуре x86/x64 младший байт хранится по меньшему адресу, а не как мы привыкли писать число от старшего разряда.

# Исследование 3. Число и текст 
Текст: Привет
Количество символов: 6
Количество байтов UTF-8: 12
Байты: D0-9F-D1-80-D0-B8-D0-B2-D0-B5-D1-82

Текст: ABC
Количество символов: 3
Количество байтов UTF-8: 3
Байты: 41-42-43

Почему количество символов и количество байтов может отличаться? 
«ABC» - 3 символа и 3 байта; «Привет» - 6 символов и 12 байтов. Кириллица в UTF-8 весит 2 байта на букву.

# Исследование 5. Обратное преобразование
Почему для обратного преобразования нужно снова указать UTF-8? 
Для обратного преобразования нужно снова указать UTF-8, потому что байты сами по себе не несут информации о своей кодировке. Кодировка как раз и является тем набором правил, который превращает байты обратно в текст.

# Исследование 6. Обратное преобразование числа 
Исходное число: 123456789
Восстановление: 123456789
Байты: 15-CD-5B-07

BitConverter 
работает с конкретным бинарным представлением числа, а: 
Encoding.UTF8 
описывает способ превращения текста в последовательность байтов.
